    A stable extension is never demoted automatically: falling below the bar is a prompt to add the missing specs or docs. One below it only by age needs nothing but time.

    The bar

    CriterionAn experimental extension needs
    specs≥ 25 tests in its own spec files
    edge speca fuzz or edge-case spec
    coverage≥ 80% line coverage of its files
    docsevery option in its section of the manual and typed in lua/org/_meta
    healtha health check (:checkhealth org)
    releases, agein ≥ 3 minor releases, and ≥ 30 days since its first commit
    no break≥ 3 minor releases since the one with its last breaking change (or none)
    open bugsno open bug issues about it (checked by hand when not measured)
    demoenabled in the live demo (checked by hand when not measured)

    How each criterion is measured: CONTRIBUTING.md.
