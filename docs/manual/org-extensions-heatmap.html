    热力图

    org-extensions-heatmap

    稳定性：稳定（org-extensions-stability）

    类似 GitHub 贡献图的日历热力图：每周一列，每天一行，每天根据当天完成的工作量着色。

    require("org").setup({ extensions = { heatmap = { weeks = 26 } } })

    :Org heatmap [clock|closed|habit] [tag|file]，或操作 heatmap_open（<prefix>Vh）。类型：

    clock计时分钟数（CLOCK 行；跨午夜的时间会分到两天，正在进行的计时会计算到现在；计算经过的时间，类似时间表，因此跨夏令时变更的时间会多算或少算一小时）
    closed标记为完成的任务：CLOSED 日期、- State "DONE" 和 - CLOSING NOTE 日志条目以及 LAST_REPEAT 属性，每个任务每天只计一次
    habit与 closed 相同，但仅针对习惯（STYLE: habit）

    习惯只有在标记为完成并记录日志时才会留下痕迹：启用 log_repeat（默认）时，每次完成都会被计数；关闭时，只有最后一次（其 LAST_REPEAT，计时任务也会有）会被计数。

    单个单词视为标签（+work 和 :work: 也可以）；以 .org 结尾的路径是数据来源。

    有五种深浅：空日，然后四个级别。默认情况下，级别将有值的日期按四分位数划分；thresholds 设置每个级别的下限（例如 { 30, 60, 120, 240 } 分钟）。颜色由 color_group 的前景和 Normal 的背景混合而成，并跟随配色方案变化；colors 设置全部五种。网格下方显示：总计、活跃天数、活跃日的平均值、当前连续天数（到今天为止，或如果今天为空则到昨天）、最长连续天数和最佳单日。

    光标从今天开始；底部行显示所选日期的总计及其最大条目。设置 weeks = 0 时，周数会跟随编辑器宽度调整。只计算显示的日期，因此多年的 CLOCK 行也很快（100,000 条记录：约 30 毫秒）。

    按键

    <Tab>下一种类型（clock、closed、habit）
    h / l上一周 / 下一周
    k / j上一天 / 下一天
    <CR>该天的日程（分割的热力图保持打开）
    r刷新
    <Esc> q退出

    选项（默认值）

    kind"clock"
    source"agenda"
    tagnil
    weeks0（适应窗口，最多 53）
    cell"■"
    thresholdsnil
    color_group"DiagnosticOk"
    colorsnil
    layout"float"
    keysnext_kind, prev_week, next_week, next_day, prev_day, agenda, refresh, quit

    高亮组：OrgHeatmap0 到 OrgHeatmap4（深浅程度，从选项设置），OrgHeatmapTitle、OrgHeatmapHint、OrgHeatmapLabel、OrgHeatmapValue、OrgHeatmapDetail。
