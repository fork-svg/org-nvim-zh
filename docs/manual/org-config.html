    org-config

    Recommended options

    org-config-recommended

    The options most setups change, with their defaults. The rest of this chapter lists every option. Unknown top-level options passed to setup() emit a warning with suggestions (:checkhealth org checks nested options and extension options too).

    org_directory = "~/org"Base directory: relative paths (capture targets, ...) start here. org-faq-capture
    agenda_files = {}Files, directories (not recursive) and globs the agenda reads. Empty: the agenda shows nothing. org-agenda
    default_notes_file = "~/.notes"Where captures without a target go. org-capture-templates
    todo_keywords = { "TODO | DONE" }Keyword sequences: { "TODO(t) NEXT(n) | DONE(d) CANCELLED(c)" }. org-todo
    log_done = false"time" adds CLOSED: when an entry is done, "note" also asks for a note. org-todo
    log_into_drawer = falsetrue puts state changes and notes in a :LOGBOOK: drawer. org-todo
    startup_folded = "showeverything"Folding when a file opens: "overview", "content", "show2levels", ... org-folding
    mappings.prefix = "<leader>o"What <prefix> means in the default keys. org-keymaps
    capture.templates = {}Capture templates by key; empty: one "Task" template into default_notes_file. org-capture-templates
    refile.targets = {}Where refile can move entries; empty: the level-1 headlines of the current file (refile.max_level adds the agenda files). org-refile
    agenda.span = "week"Days in the agenda: "day", "week", "fortnight", "month", "year" or a number. org-agenda
    agenda.custom_commands = {}Your own views in the agenda dispatcher. org-agenda-custom-commands
    deadline_warning_days = 14Days before a deadline it starts showing in the agenda. org-agenda
    ui.indent_mode = falseVirtual indentation of body text (org-indent-mode). org-indent
    ui.hide_emphasis_markers = falseHide the *, /, _, =, ~ and + around emphasized text. org-appearance
    picker = "auto"The picker of the pick_* actions: snacks, fzf-lua, telescope, mini or vim.ui.select. org-pickers
    notifications.enabled = falseReminders before entries with a time today. org-notifications
    extensions = {}Optional extensions: roam, ql, journal, ... org-extensions

    A setup with the usual changes:

    require("org").setup({
  org_directory = "~/org",
  agenda_files = { "~/org/**/*.org" },
  default_notes_file = "~/org/inbox.org",
  todo_keywords = {
    "TODO(t) NEXT(n) WAITING(w@) | DONE(d) CANCELLED(c@)",
  },
  log_done = "time",
  log_into_drawer = true,
  startup_folded = "content",
  refile = { max_level = 2 },
  ui = { indent_mode = true, hide_emphasis_markers = true },
  notifications = { enabled = true },
  capture = {
    templates = {
      t = { description = "Task", target = "inbox.org",
            template = "* TODO %?\n  %U" },
      n = { description = "Note", target = "notes.org",
            headline = "Notes", template = "* %?\n  %U" },
    },
  },
})
