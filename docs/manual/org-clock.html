    计时和工作量

    org-clock
    <prefix>xi在当前条目开始计时。如果有正在运行的计时会先停止，clock.in_switch_to_state 可以更改 TODO 状态。计数可以从计时历史中选择任务（d 默认任务，i 被中断的任务，c 当前任务，1-9 A-Z 最近的任务）；16 还会将条目标记为默认任务；64 从上次计时停止的地方开始。
    <prefix>xo停止计时（全局）。clock.out_switch_to_state 更改 TODO 状态；使用计数时，会询问你要设置的状态。
    <prefix>xq取消正在运行的计时（全局）。
    <prefix>xj跳转到正在计时的条目（全局），否则跳转到上次计时的条目。使用计数时，从历史中选择。
    <prefix>xe设置工作量。
    <prefix>xE将工作量设置为 Effort_ALL 的下一个值。
    <prefix>xm更改正在计时任务（或光标处条目）的工作量；+0:15 / -10 增加或减少。
    <prefix>xz解决未关闭的计时（使用计数：只处理悬挂的计时，不处理正在运行的计时）。参见 org-clock-resolve。
    <prefix>xd在每个子树的标题旁显示计时时间，范围为 clock.display_default_range（今年）。计数：4 = 今天，16 = 询问范围，64 = 仅总计。编辑缓冲区、按 <C-c><C-c> 或再次调用会隐藏总计。与 Emacs 一样，总计覆盖标签，也会显示在折叠的标题上；时间对齐在显示的标题上。
    org-clocktable
    <prefix>xr在光标处的条目（:scope 子树）或第一个标题前的文件中插入计时报告（#+BEGIN: clocktable）；如果在报告上则更新它。使用计数时，更新缓冲区的第一个计时表。新块获得 clock.clocktable_default_properties。总计和文件时间单元格使用 clock.total_time_cell_format / clock.file_time_cell_format（"*%s*"）。clock.clocktable_formatter 替换表格写入器：function(tables, params) 接收 { { file, time, entries = { { level, headline, tags, timestamp, time (分钟), properties } } } } 和块参数，并返回块的行（org-clock-clocktable-formatter）。
    <C-c><C-c>在 CLOCK 行上：重新计算其持续时间。
    <C-S-Up/Down>在 CLOCK 行上：按光标下的部分移动两个时间戳，保持持续时间不变。
    <M-K> / <M-J>在 CLOCK 时间戳上（Emacs S-M-Up/Down）：更改它，并在计时历史中按相同量移动上一个（开始计时时）或下一个（停止计时时）任务的时间戳。
    <S-arrows>在 #+BEGIN: clocktable 行上：移动其 :block（today -> today-1, 2026-W39 -> 2026-W40, ...）。
    :Org clock_in_last再次开始上次计时的条目（计数：从历史中选择；16 = 从上次停止计时开始；64 = 询问 TODO 状态）。
    :Org clock_mark_default_task将条目标记为默认任务。
    :Org clock_toggle_auto_clockout开启/关闭此会话的自动停止计时。

    计时行进入 LOGBOOK 抽屉：

    :LOGBOOK:
CLOCK: [2026-09-23 Wed 10:00]--[2026-09-23 Wed 11:30] =>  1:30
:END:

    与 Emacs 一样，计时行在其持续时间后没有任何内容（任何情况下都是 CLOCK:）；后面有文本的行是段落，其时间不会被计算。单独的 CLOCK: => 2:00 会为条目的计时总计添加两小时，无论其时间范围。开始时间没有时间戳的计时（[2026-09-23 Wed]--...）不计入，结束时间没有时间戳的则取开始时间（org-clock-sum）。结束时间早于开始时间的计时也不计入：在计时表、CLOCKSUM、状态栏总计、按计时时间排序以及汇总计时的扩展中。

    抽屉来自继承的 CLOCK_INTO_DRAWER 属性（nil 表示无，数字 N 表示"一旦有 N 行计时"），然后是 clock.into_drawer，最后是日志抽屉。启用 log_note_clock_out（或 #+STARTUP: lognoteclock-out）时，停止计时会要求输入备注，备注放在 CLOCK 行下方。clock.continuously 从上次计时停止的地方开始新计时，clock.rounding_minutes 像 Emacs 一样四舍五入计时时间（org-current-time）：停止计时取最近的倍数，平局时取偶数（10 分钟时，10:25 变为 10:20）；开始计时永远不会在未来开始（10 分钟时，10:27 变为 10:20）。clock.in_resume 继续条目的未关闭 CLOCK 行。

    将正在计时的任务标记为完成会停止计时（clock.out_when_done：true 或状态列表）。重启 Neovim 后会恢复正在运行的计时（clock.persist：true、"clock" 或 "history"），在询问后（clock.persist_query_resume）。在计时运行中退出时会询问是否先停止计时并保存（clock.ask_before_exiting）。0:00 的计时会保留，除非设置了 clock.out_remove_zero_time。

    状态栏显示 [clocked/effort] (Task)，其中计时时间包括任务之前的计时（clock.mode_line_total 或 CLOCK_MODELINE_TOTAL 属性：current、today、repeat、all、auto = 对于重复任务从 LAST_REPEAT 开始）。一旦达到工作量，你会收到一次通知（clock.notify_effort、clock.sound、clock.notification_handler），并在前面添加 clock.task_overrun_text。

    用户自动命令：OrgClockInPrepare（在写入 CLOCK 行之前，例如设置工作量）、OrgClockIn、OrgClockOut、OrgClockCancel、OrgClockGoto。

    org-clock-resolve

    解决计时

    不是正在运行计时的未关闭 CLOCK 行是悬挂的（例如崩溃后）。开始计时会先解决它们（clock.auto_clock_resolution），在空闲 clock.idle_time 分钟后，你会被询问关于正在运行的计时（macOS 和 xprintidle 使用系统空闲时间）。按键：

    k / K保留 N 分钟（默认全部），保持计时中 / 停止计时
    t / T保留到给定时间
    g / G你 N 分钟前回来：离开时停止计时，从那时开始计时（G：保持停止）
    s / S减去空闲时间：现在重新开始计时（S：保持停止；下次开始计时时提供从减去时间开始的选项）
    C取消计时
    j / J跳转到计时（J：先停止计时）
    i / q忽略

    clock.auto_clockout_timer 在空闲那么多秒后停止计时。

    org-durations

    持续时间

    持续时间是带单位的数字，可选地以 H:MM 或 H:MM:SS 结尾：3:12、1:23:45、1y 3d 3h 4min、1d3h5min、3d 13:35、2.35h；单独的数字是分钟。单位及其分钟数来自 duration_units（Emacs org-duration-units）：

    duration_units = { min = 1, h = 60, d = 1440, w = 10080, m = 43200, y = 525960 }

    设置 d = 480、w = 2400 使 1d 在工作量和列总和中表示 8 小时工作日；可以添加新单位（wd = 480）。年龄（{@min} ...）保持标准的 min/h/d。

    计时表、计时总和、计时状态行、工作量更改和列摘要中的持续时间用 duration_format（Emacs org-duration-format）编写：

    "d h:mm"从一天开始 1d 2:30，否则 2:30（默认值，Emacs (("d" . nil) (special . h:mm))）
    "h:mm"26:30
    "h:mm:ss"26:30:00
    列表

    { unit, required } 条目、{ "special", mode } 和 "compact" 的列表：值为零的单位被删除，除非必需；模式 "h:mm" / "h:mm:ss" 将大于小时的最小单位下的时间写为 H:MM(:SS)；小数位数写一个带分数的单位（第一个必需单位或不大于持续时间的单位）；"compact" 删除空格。示例：{ { "d" }, { "h", true }, { "min", true } } 1d 2h 30min

    { { "d" }, { "h" }, { "special", 2 } }1.10d
    { { "h", true }, { "special", 2 } }26.50h
    { { "w" }, { "special", "h:mm" }, "compact" }1w32:00

    字典形式也可以：{ d = false, special = "h:mm" }。

    在状态栏中使用 org-api require("org").statusline()。
