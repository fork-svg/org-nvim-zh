    动态块

    org-dblocks
    #+BEGIN: clocktable :scope file :maxlevel 2 :block thisweek
#+END:
    <prefix>xu / xU更新光标处的块 / 所有块。在 #+BEGIN: 行按 <C-c><C-c> 也可更新。

    clocktable 参数（输出与 Emacs 9.8 一致）：

    :scopefile|subtree|tree|treeN|agenda|agenda-with-archives| file-with-archives|("a.org" "b.org")
    :maxlevelN (default 2)
    :blocktoday, yesterday, thisweek, lastweek, thismonth, lastmonth, thisq, lastq, thisyear, lastyear（this* 形式和 today 可接受 -N / +N），untilnow, 2026-09-23, 2026-W39, 2026-Q3, 2026-09, 2026。此参数优先于 :tstart / :tend。
    :tstart / :tend时间戳或 <now>、<today>、<yesterday>、<tomorrow>、<-2d>、<+1w>、<-3h>（h 从现在算起，d w m y 从今天算起）
    :wstart / :mstart一周的第一天（1 = 周一）/ 月份的第一天
    :stepday|week|semimonth|month|quarter|year：按 :block 或 :tstart/:tend 范围内的每个周期生成一个表格（:stepskip0 t 跳过空周期）
    :match匹配字符串（org-match-syntax）
    :formula% 添加百分比列；"$3=$2;t" 添加 #+TBLFM 行。表格下方的 #+TBLFM 在更新时会保留。
    :sort (2 . ?T)按列排序行（a/A n/N t/T）
    :lang de表头语言：de（德语）、es（西班牙语）、fr（法语）、nl（荷兰语）、nn（新挪威语）、pl（波兰语）、pt-BR（巴西葡萄牙语）或 sk（斯洛伐克语）
    :filetitle t在文件列中使用 #+TITLE 而不是文件名
    :properties ("Effort" "OWNER")属性列（:inherit-props t 启用继承）
    :level t层级列
    :timestamp t时间戳列
    :tags t标签列
    :emphasize t第1级标题加粗，第2级斜体
    :link t为标题添加链接
    :fileskip0 t跳过没有时间的文件
    :hidefiles t不显示文件列
    :tcolumns N最多 N 个时间列
    :compact t单个时间列，标题缩进
    :indent nil不使用 \_ 缩进
    :narrow 40!将标题截断为 40 个字符（默认值）；:narrow 40 则添加 <40> 宽度行
    :header "text"替换 #+CAPTION: 行

    columnview 参数：:id local|global|file:path|ID（默认 local；local 或 ID 视图覆盖持有 COLUMNS 属性的条目所继承的子树，否则是该条目自己的子树，与列视图行为一致），:maxlevel，:skip-empty-rows，:indent，:format，:match（标签/属性匹配），:exclude-tags (a b)（继承的标签也算），:hlines t|N（在每个条目前添加水平线，或在 N 级及以下的条目前添加），:vlines t（列分组），:link t（将项目链接到其标题），:formatter（全局 Lua 函数名 function(rows, params) 返回行内容；columns_dblock_formatter 为每个块设置格式化器；rows 包含标题、"hline"，然后是 { level = n, hl = headline, cells... }）。与 Emacs（org-columns-dblock-write-default）一样，当格式有宽度时，会写入宽度标记行（<25>），列会收缩；ITEM 会失去统计标记、脚注引用、目标和内联源代码块/调用；已归档和注释的子树会被跳过。#+NAME: 等关键字和表格下方的第一个 #+TBLFM: 行会保留，公式会重新应用。值中的 | 会写为 \vert{}（Emacs 直接写入原始字符，会破坏表格）。

    自定义块：

    require("org.dblock").register("myblock", function(params, ctx)
  return { "| generated | table |" }
end)
